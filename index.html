Sudoku

Fill each row, column, and 3 × 3 box with the digits 1–9, without repeats. Shaded starting numbers are locked. Select a white cell to type; use Backspace or Delete to clear it. Turn Notes on to toggle possible digits in empty cells; turn it off to enter an answer. Use Undo to reverse the latest answer or pencil-note change. Select an answer or starting number to highlight matching numbers. Select an empty cell to clear highlights; pencil notes do not count as answers.
